# Эхо — сайт и Echo Studio

Интерфейс EchoWeb подключён к Spring API этого репозитория через `src/echo-api.js`. Страницы и сценарии находятся в `src/app.js`. Исходные `API.md`, `BACKEND.md` и `src/api.js` сохранены как материалы импортированного фронта; рабочая интеграция использует `src/echo-api.js`.

## Локальная разработка

Нужен Node.js 24. Запустите Spring API на порту 3001, затем в этой папке:

```bash
npm ci
VITE_API_URL=/api VITE_DEV_PROXY=http://127.0.0.1:3001 npm run dev
```

Без `VITE_API_URL` интерфейс показывает демонстрационные данные. При сборке Docker образа переменная выставляется автоматически, и сайт обращается к реальному API через nginx.

Главная показывает небольшую подборку популярных фильмов и классики. Каталог загружает страницы TMDB по запросу; год, жанр, страна и сортировка применяются на стороне TMDB. Поиск обращается ко всей базе фильмов TMDB, а полная карточка загружается при открытии фильма.

## Сервер

Порядок настройки секретов, запуска PostgreSQL, Spring и nginx описан в [инструкции развёртывания](../docs/DEPLOY_IP_RU.md). Сборку можно проверить командой `npm run build`.
