# Админ-панель «Эхо»

> **Цель:** модерация рецензий, проверка новых пользователей и авторов, журнал решений команды · **Обновлено:** 12.11.2026 · **Ответственный:** Роман Стяжкин (PM)

Статическая страница без сборки и зависимостей: `index.html`, `admin.js`, `admin.css`, `config.js` и `demo.js`. Оформление — в токенах сайта v10.40.

| Раздел | Что делает |
|---|---|
| Обзор | Счётчики очередей, самая старая рецензия в очереди, итоги за 7 дней |
| Рецензии | Очередь / Опубликованные / Отклонённые. Оценка по 5 параметрам, автопроверка длины (150–10 000), подсветка подозрительной лексики и возможных спойлеров. Опубликовать, отклонить с причиной, снять с публикации. Горячие клавиши: `A` — опубликовать, `R` — отклонить, `J`/`K` — следующая и предыдущая |
| Пользователи | Новые / Проверенные / Заблокированные. Карточка с активностью и последними рецензиями. Отметить проверенным, сменить ник, выдать «Медиа», заблокировать или разблокировать, назначить модератора (только ADMIN) |
| Авторы | Заявки / Верифицированные / Отклонённые. Верифицировать, отклонить, запросить подтверждение |
| Журнал действий | Кто, что, над чем и когда |

## Посмотреть без бэкенда

Откройте `index.html?demo` через любой локальный сервер, например `npx serve admin-panel` → `http://localhost:3000/?demo`. Данные вымышленные и живут только в браузере.
