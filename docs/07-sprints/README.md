## Как вести страницу спринта
Новый спринт — файл `sprint-NN.md`: даты, цель, таблица задач (ответственный, оценка, ссылка на Issue), в конце — итоги (что сделано, что перенесено и почему). Решения — в [лог решений](../02-management/decisions-log.md).
