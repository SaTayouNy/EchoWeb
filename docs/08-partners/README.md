# Партнёрам «Эхо»

> **Цель:** всё, что нужно авторам, студиям и организациям для работы с «Эхо», в одном месте · **Обновлено:** 23.10.2026 · **Ответственный:** Роман Стяжкин (PM)

## Что такое «Эхо»
Платформа для осмысленных рецензий на кино. Зрители оценивают фильм по пяти параметрам — драматургия, персонажи, визуальный язык, звук и впечатление — и объясняют своё восприятие в рецензии. Авторы фильмов видят, что именно зрители заметили в их работе, и отвечают авторским комментарием в кабинете **Эхо Studio**.

**Запуск — 1 ноября 2026.** Сейчас мы формируем первую группу авторов и партнёров, с которыми развиваем продукт вместе.

## Что мы предлагаем

| Формат | Что это |
|---|---|
| Страница фильма | Карточка фильма с описанием, составом, оценками и рецензиями зрителей |
| Страница автора | Профиль с подтверждёнными работами; авторский комментарий к своему фильму; лайк автора на рецензии, которые вам близки |
| Блок партнёров на главной | Анонс фильма, программы или события |
| Материалы в соцсетях | Посты об авторе и фильме в VK и Telegram «Эхо» |
| Обратная связь по продукту | Предложения функций через карточки ниже — они влияют на развитие платформы |

**Условия:** на старте сотрудничество **бесплатное и без обязательств**.
**Чего мы не обещаем:** количество просмотров, рост аудитории или продаж. Мы молодой проект и честно говорим об этом.

## Как начать
1. Напишите нам через форму на лендинге для авторов или в Telegram-канал проекта (ссылки — на сайте «Эхо»).
2. Пришлите материалы по чек-листу ниже.
3. Мы оформим страницу фильма и автора и дадим доступ в Эхо Studio.

### Чек-лист материалов о фильме
- [ ] Название, год, страна, хронометраж, жанр
- [ ] Краткое описание без спойлеров (до 500 знаков)
- [ ] Постер (вертикальный, от 1000 px по высоте)
- [ ] Режиссёр и ключевые участники: имя, роль, фото (по желанию)
- [ ] Ссылка, где фильм можно посмотреть, если он доступен
- [ ] Разрешение на размещение постера, описания и, при наличии, кадров
- [ ] Данные для аккаунта автора: имя, специальность, желаемый логин

## Предложить функцию
Если вам не хватает возможности на платформе — заполните **карточку функционала**. Все карточки собираются в один реестр: [реестр карточек партнёров](feature-cards.md).

**[➕ Заполнить карточку функционала](https://github.com/SaTayouNy/EchoWeb/issues/new?template=partner-feature.yml)**

- Нужен бесплатный аккаунт GitHub.
- Карточки **публичные**: не указывайте телефоны, личную почту и закрытую информацию.
- Нет аккаунта GitHub — отправьте те же поля ([шаблон ниже](#шаблон-карточки-без-github)) PM в Telegram, и мы внесём карточку сами.

### Что будет с карточкой
1. Карточка попадает в реестр со статусом «Новая» автоматически.
2. PM рассматривает её на ближайшем планировании (раз в неделю).
3. Статус меняется: **Принята** (в плане), **Отложена** (после проверки основной гипотезы), **Отклонена** (с объяснением в комментарии), **Реализована**.
4. Ответ — в комментариях к карточке.

> До релиза и около месяца после него функционал не расширяется: сначала проверяем основную гипотезу продукта. Карточки, поданные сейчас, рассматриваются для следующего этапа.

### Шаблон карточки без GitHub
```
Организация / автор:
Название функции:
Какую проблему решает:
Для кого (зритель / автор / медиа / партнёр):
Как это должно работать (сценарий по шагам):
Ожидаемый результат:
Важность для вас (критично / важно / желательно):
Пример или референс (ссылка, скриншот):
```
