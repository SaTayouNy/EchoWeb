# Внешние сервисы

> **Цель:** зафиксировать, какие внешние сервисы используются и что подключаем позже · **Обновлено:** 23.10.2026 · **Ответственный:** Иван Зуев (BE), Роман Стяжкин (PM)

## Используем к релизу

| Сервис | Зачем | Где подключён | Стоимость |
|---|---|---|---|
| **TMDB API** | Данные фильмов: название, год, жанры, состав, постеры | Бэкенд (`APP_TMDB_PROVIDER=http`, ключ в переменных окружения) | Бесплатно (некоммерческое использование, обязательна атрибуция TMDB) |
| **Яндекс.Метрика** | Посещаемость, события, вебвизор, воронки | Фронт | Бесплатно |
| **Google Analytics 4** | Дублирование событий, сравнение с Метрикой | Фронт | Бесплатно |
| **GitHub** | Код, вики, задачи, карточки партнёров | — | Бесплатно |

## После релиза (по необходимости)

| Сервис | Зачем | Когда |
|---|---|---|
| Sentry | Ошибки фронта и бэкенда | Первые недели после релиза |
| Почтовый сервис (SMTP / SendGrid / Unisender) | Подтверждение почты, восстановление пароля, рассылки остывшим пользователям | После согласия на обработку персональных данных |
| reCAPTCHA v3 / SmartCaptcha | Защита регистрации от ботов | При появлении спама |
| Объектное хранилище (S3-совместимое) | Аватары и постеры файлом | Когда появится загрузка файлов |
| Кинопоиск API / OMDb | Дополнение данных о российских и короткометражных фильмах | При необходимости |

## Правила
- Ключи — только в переменных окружения сервера, никогда в репозитории и во фронте.
- Новый сервис подключается через [запрос на изменение](../02-management/change-management.md) и добавляется в эту таблицу.
- Недоступность сервиса не ломает сайт: при ошибке TMDB показываются кэш или заглушки.
