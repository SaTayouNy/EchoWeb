# Выкладка

> **Цель:** описать, как собирается и выкладывается продукт · **Обновлено:** 23.10.2026 · **Ответственный:** Иван Зуев (BE), Анна Киракосян (FE)

## Окружения

| Окружение | Ветка | Назначение |
|---|---|---|
| Локальное | любая | Разработка: фронт на демо-данных или с локальным бэкендом |
| Тестовое (staging) | `develop` | Интеграционное тестирование перед релизом |
| Продакшен | `main` + тег версии | Пользователи, с 01.11.2026 |

Сервер и домен выбираются в задаче хостинга спринта 7; требования — VPS в РФ, Linux, 2 vCPU / 4 ГБ, HTTPS (Let's Encrypt).

## Фронтенд
```bash
echo "VITE_API_URL=/api" > .env
npm ci && npm run build       # результат — папка dist/
```
`dist/` — статические файлы, Node.js на сервере не нужен. Адрес API вшивается при сборке: после смены `.env` пересоберите.

## Бэкенд
```bash
mvn clean package
SPRING_PROFILES_ACTIVE=prod APP_TMDB_PROVIDER=http java -jar target/*.jar
```
- Запуск как systemd-сервис с автоматическим перезапуском.
- Секреты (пароль БД, ключ TMDB, ключ подписи токенов) — в переменных окружения сервиса.
- БД — PostgreSQL; ежедневная резервная копия (`pg_dump` по расписанию), хранение 7 дней.

## nginx
```nginx
server {
  server_name echo.example.ru;
  root /var/www/echo/dist;
  location / { try_files $uri /index.html; }
  location /api/ { proxy_pass http://127.0.0.1:3000/; }
}
```
Сайт и API на одном домене — CORS не нужен.

## Релиз
1. Всё для релиза влито в `develop` и проверено на staging по [чек-листу](testing.md).
2. PR `develop` → `main`, ревью PM.
3. Тег `vX.Y.Z` на `main`, сборка и выкладка.
4. Проверка продакшена: главная, вход, рецензия, аналитика.
5. Запись в [журнал решений](../02-management/decisions-log.md), если менялось что-то значимое.

**Откат:** выложить предыдущий тег; БД восстанавливается из последней резервной копии (RTO < 30 минут).
