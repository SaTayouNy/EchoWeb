## Чек-лист сценариев

**Гость:** главная → каталог с фильтрами → поиск → фильм → начать рецензию → предложение войти, черновик сохранён.
**Зритель:** регистрация (занятый логин → ошибка) → вход → оценка без рецензии → рецензия < 150 символов (ошибка) → рецензия ≥ 150 со спойлером → «на модерации» → лайк и снятие лайка → топ-5 предпочтений (6-й не добавляется) → редактирование профиля → выход.
**Повтор:** вторая рецензия на тот же фильм невозможна; итог оценки совпадает с формулой; баллы и статус обновились.
**Автор:** заявка → «ожидает подтверждения» → после подтверждения вход в Studio → лайк автора на рецензию к своему фильму → нельзя к чужому → авторский комментарий → замена комментария.
**Админ:** одобрить и отклонить рецензию, подтвердить автора.
**Сессия:** истёкший access-токен обновляется незаметно; истёкший refresh → повторный вход без потери черновика.
