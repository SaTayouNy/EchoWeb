## Коротко о проекте

- **Что:** платформа для осознанного взаимодействия с кино — оценки по параметрам, рецензии, сообщество зрителей, медиа и авторов.
- **Прообраз:** российский проект о музыкальных рецензиях «Риса за Творчество» (РЗТ), перенесённый на кино. РЗТ — ориентир по UX и дизайну.
- **Статус:** учебный социальный проект колледжа. Бюджета на привлечение пользователей нет, на старте ожидается небольшая аудитория.
- **История:** первая итерация — январь–июнь 2026. После перерыва примерно в 3 месяца сохранены архитектура бэкенда и база данных, интерфейс создан заново.
- **Запуск:** 1 ноября 2026.
- **Виза руководителя:** получена 24.11.2025 (см. [заинтересованные лица](stakeholders.md)).
