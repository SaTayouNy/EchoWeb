# Цели и задачи проекта

> **Цель:** зафиксировать цель проекта, этапы и продуктовые задачи · **Обновлено:** 23.10.2026 · **Ответственный:** Роман Стяжкин (PM)

## Цель

Создать инструмент для самовыражения, который даёт совокупность конструктивных мнений и на выходе — сбалансированное представление о ценностях другого человека через кино.

## Этапы проекта

| # | Этап | Статус на 23.10.2026 |
|---|---|---|
| 1 | Инициация: обоснование, заявка, маркетинговый анализ | ✅ Выполнено |
| 2 | Проектирование: UX/UI, архитектура | ✅ Выполнено |
| 3 | Разработка MVP | 🔄 Финальный спринт: интеграция фронтенда и бэкенда |
| 4 | Тестирование MVP: гипотеза, функциональное, нагрузочное, безопасность | 🔄 Спринт 7 (23–30.10) |
| 5 | Открытый релиз | ⏳ 1 ноября 2026 |
| 6 | Сбор обратной связи и анализ поведения пользователей | ⏳ Около месяца после релиза |
| 7 | Развитие сообщества: Telegram, VK, подборки, премии | 🔄 Идёт параллельно, см. [программу](../06-community/social-program.md) |
| 8 | Поддержка и развитие продукта | ⏳ После проверки основной гипотезы |

> Решение (см. [лог решений](../02-management/decisions-log.md)): **до релиза и около месяца после него функционал не расширяется**. Сначала проверяется основная гипотеза продукта.

| Задача | Где реализовано / статус |

| Условия для осознанного погружения: интерфейс без визуального шума, качественная типографика | [Требования к оформлению рецензий](../03-product/review-design.md) |

| Понятное отображение мнений пользователей | Три средние оценки и параметры на странице фильма |
