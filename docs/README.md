# Wiki проекта «Эхо»

> **Цель:** единая точка входа во всю документацию проекта · **Обновлено:** 23.10.2026 · **Ответственный:** Роман Стяжкин (PM)

Wiki — **единственный источник актуальной информации** о проекте. При спорах правдой считается то, что записано здесь (см. [Правила работы с Wiki](02-management/wiki-rules.md)).

«Эхо» — платформа для осмысленного взаимодействия с кино: зрители оценивают фильмы по параметрам качества и впечатлению, пишут рецензии и читают чужие, авторы фильмов получают аргументированную обратную связь. Запуск — **1 ноября 2026**.

## Как устроена wiki

- Каждая страница — файл Markdown в папке `docs/`. GitHub показывает их как обычные страницы.
- Изменения вносятся через pull request (см. [Правила работы с Wiki](02-management/wiki-rules.md)). Мелкие правки в своей зоне ответственности можно делать прямо в веб-интерфейсе GitHub кнопкой ✏️.
- В начале каждой страницы: цель, дата обновления, ответственный.
- Устаревшее не удаляется, а переносится в [архив](archive/README.md).

## Глоссарий

| Термин | Значение |
|---|---|
| **Зритель** | Основная роль пользователя: оценивает фильмы, пишет и читает рецензии |
| **Медиа** | Роль издания или критика (внутри команды иногда «критики» — это одна и та же роль) |
| **Автор** | Создатель фильма (режиссёр, актёр, оператор и т. д.), прошедший верификацию; работает в кабинете **Эхо Studio** |
| **Рецензия** | Текстовое мнение зрителя или медиа с оценкой по параметрам |
| **Авторский комментарий** | Контекст от автора на странице его фильма. Не рецензия и не ответ на рецензию (раньше назывался «авторская рецензия») |
| **Лайк автора** | Отметка автора на рецензии к его фильму; самое ценное действие в системе статусов |
| **Качество** | Четыре параметра того, как сделан фильм. Не «мастерство» |
| **Впечатление** | Пятый параметр — личный отклик. Не «субъективное мнение» |
| **Статус (светлячок)** | Уровень вовлечённости пользователя по баллам: Искра → Мята → Лазурь → Аметист → Рубин → Полярный |
| **NSM** | North Star Metric: рецензии / WAU / неделя |
| **Эхо Studio** | Кабинет автора: обзор, фильмография, мнения зрителей, авторские комментарии, профиль |
