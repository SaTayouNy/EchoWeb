## Что изменилось в октябре 2026

Wiki, задачи и код переехали в GitHub-репозиторий **SaTayouNy/EchoWeb**. Сервисы колледжа (Redmine, Panda-disk, локальная wiki) работают только по доступу колледжа и не подходят для работы с партнёрами и долгосрочной поддержки. Подробности — в [логе решений](decisions-log.md).

| Было | Стало |
|---|---|
| Wiki колледжа | Папка `docs/` в репозитории |
| Redmine | GitHub Issues + доска GitHub Projects |
| Panda-disk | `docs/` для текстов; макеты остаются в Figma |
| Запрос на изменение в чате | Форма «Запрос на изменение» в Issues |
