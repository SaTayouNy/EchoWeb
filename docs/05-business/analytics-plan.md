# План аналитики

> **Цель:** определить, какие события собираем в Яндекс.Метрике и GA4 и какие отчёты строим · **Обновлено:** 23.10.2026 · **Ответственный:** Роман Стяжкин (PM), Анна Киракосян (FE)

## Подключение
- Счётчики Яндекс.Метрики и GA4 подключаются во фронте; идентификаторы задаются переменными сборки, а не в коде.
- События отправляются из одного места — функции-обёртки, которая вызывает оба сервиса.
- На тестовом сервере и при `npm run dev` события не отправляются.
- В событиях нет персональных данных: ни логинов, ни текстов рецензий.

## События

| Событие | Когда | Параметры | Для какой метрики |
|---|---|---|---|
| `sign_up` | Успешная регистрация | `role` | Активация |
| `login` | Успешный вход | `role` | — |
| `movie_card_view` | Открыта страница фильма | `movie_id`, `source` (главная, каталог, поиск) | Просмотренные карточки |
| `review_expand` | «Читать полностью» | `movie_id` | Раскрытые рецензии |
| `review_start` | Первое изменение формы оценки | `movie_id` | Начатые рецензии |
| `rating_submit` | Сохранена оценка без текста | `movie_id` | Активация |
| `review_submit` | Рецензия отправлена | `movie_id`, `length`, `spoiler` | **NSM**, законченные рецензии |
| `review_like` | Лайк рецензии | — | Социальная ценность |
| `author_like` | Лайк автора | — | Социальная ценность |
| `author_comment_publish` | Авторский комментарий | — | Активность авторов |
| `preferences_save` | Сохранён топ-5 | `type` | Вовлечённость |
| `search` | Выполнен поиск | `results` (число) | — |
| `partner_block_view` | Блок партнёров попал в экран | `partner` | Показы партнёрского контента |
| `partner_click` | Переход по партнёрскому материалу | `partner` | CTR интеграций |
| `mobile_stub_view` | Показан экран-заглушка | — | Спрос на мобильную версию |
| `author_landing_view` | Открыт лендинг для авторов | `utm_source` | Привлечение авторов |
| `error_shown` | Пользователь увидел ошибку | `code`, `screen` | Качество |

## Цели и воронки
1. **Активация:** визит → `sign_up` → первая `rating_submit` или `review_submit` в течение 7 дней.
2. **Рецензия:** `movie_card_view` → `review_start` → `review_submit` (доля дошедших — качество формы).
3. **Партнёры:** `partner_block_view` → `partner_click`.

## Отчёты

| Отчёт | Частота | Кто смотрит |
|---|---|---|
| WAU, NSM, новые регистрации | Еженедельно на планировании | Вся команда |
| Воронка рецензии, ошибки | Еженедельно | PM, FE |
| Rolling Retention 7d по когортам | Раз в 2 недели | PM |
| Показы и переходы партнёров | Ежемесячно, отчёт партнёру | PM |
