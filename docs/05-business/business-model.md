# Бизнес-модель и цепочка метрик

> **Цель:** зафиксировать модель монетизации и связь продуктовых метрик с выручкой · **Обновлено:** 23.10.2026 · **Ответственный:** Роман Стяжкин (PM)

## Модель

**Единая партнёрская модель:** платные интеграции и размещения для фестивалей, киношкол, культурных организаций и релевантных сервисов.
Платная ценность для партнёра — **доступ к активной аудитории и взаимодействие с его контентом**.

**Форматы:** размещение фильма или программы · спецстраницы фестивалей и проектов · тематические подборки · продвижение мероприятий · партнёрские переходы и целевые действия · аналитика взаимодействия аудитории с контентом партнёра.

**Сейчас (до 1 месяца после релиза):** партнёрство бесплатное, блок партнёров на главной — без оплаты. Задача этапа — собрать аудиторию и данные для первых платных предложений.

## Ценности ролей

| Роль | Ценности |
|---|---|
| Зритель | Понимать кино глубже; формулировать своё мнение; понимать восприятие других; находить интересное кино; вести свою историю отношений с кино; быть частью сообщества |
| Медиа (критик) | Пространство для своей критики; заинтересованная аудитория; профессиональная репутация; реакция на тексты |
| Автор | Аргументированная обратная связь; фильм в качественном контексте; заинтересованная аудитория; диалог со зрителями |

## North Star Metric

**NSM = написанные рецензии / WAU / неделя.** Показывает, создаёт ли продукт главную ценность — осмысленные высказывания.

Ограничение: NSM не отражает напрямую эффективность для партнёров. После запуска монетизации добавляется **коммерческая метрика** — взаимодействия с контентом партнёров (показы, переходы, целевые действия).

## Цепочки метрик

Общий хвост всех цепочек: **→ показы партнёрского контента → CTR интеграций → переходы → целевые действия → платные партнёры → выручка**.

| Цепочка | Начало |
|---|---|
| Активация | WAU → Activation Rate → активированные пользователи → NSM → … |
| Карточки | WAU → просмотренные карточки фильмов → NSM → … |
| Чтение | WAU → раскрытые рецензии → NSM → … |
| Письмо | WAU → начатые / законченные рецензии → NSM → … |
| Социальная ценность | WAU → социальная ценность (лайки, лайки автора) → рецензии на человека → … |
| Удержание | WAU → Rolling Retention 7d → рецензии на человека → … |

Как события собираются — в [плане аналитики](analytics-plan.md); сегменты и удержание — в [сегментах вовлечённости](../03-product/engagement-segments.md).
