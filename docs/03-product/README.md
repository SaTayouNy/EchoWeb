## Продукт одной фразой

Платформа, где кино не просто смотрят, а **рассматривают, осмысливают и обсуждают**: оценка разделяет *качество* и *впечатление*, рецензия объясняет *почему*, а авторы фильмов видят, как воспринимают их работу.

**Путь пользователя вглубь:** Просмотр → Впечатление → Оценка → Рецензия → Взаимодействие с другими.
