# Требования к оформлению рецензий

> **Цель:** обеспечить комфортное чтение и доступность рецензий — основного контента платформы · **Обновлено:** 23.10.2026 · **Ответственный:** Анна Киракосян (UX/UI)

| Требование | Значение |
|---|---|
| Контраст текста и фона | Основной текст ≥ **4,5:1**; крупный ≥ **3:1** |
| Размер основного текста | ≥ **16 px** |
| Межстрочный интервал | ≥ **1,5×** размера шрифта |
| Расстояние между абзацами | ≥ **2×** размера шрифта |
| Ширина текста | Ограничена для комфортного чтения; текст не растягивается на всю ширину |
| Масштаб до 200% | Содержимое и функции не ломаются и остаются доступными |
| Цвет | Не единственный способ передать информацию (статус, тип пользователя, параметр оценки) |
| Область нажатия | ≥ **24×24 px** |
| Наведение | Важная информация доступна не только при наведении, но и через фокус или нажатие (подсказки параметров — по `Tab`) |
| Состояния элементов | default / hover / focus / active / disabled / loading / error / empty |
| Длинные рецензии | Свёрнуты; есть кнопка «Читать полностью» |
| Спойлеры | Текст скрыт до явного действия; предупреждение текстовое («⚠ Рецензия содержит спойлеры»), а не только цветовое |
| Интерфейс вокруг | Минимум элементов: ничто не отвлекает от чтения |

## Состав карточки рецензии

| Где | Состав |
|---|---|
| Страница фильма | Аватар · никнейм · статус — оценка (итог + 5 параметров) / Заголовок / Текст / ♥ лайки · ★ лайк автора — дата |
| Главная | То же + мини-карточка фильма |
| Профиль | Постер, название, режиссёр — оценка / Заголовок / Текст / Лайки — дата |
| Эхо Studio | Как на странице фильма + фильм + кнопка лайка автора |
| Авторский комментарий | Оранжевый блок: «Авторский комментарий» / заголовок / имя автора · специальность / текст / ♥ лайки — дата |
