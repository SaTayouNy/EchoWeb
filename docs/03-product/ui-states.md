# Состояния интерфейса

> **Цель:** зафиксировать экраны, их состояния, что пользователь видит в каждом и что вызывает переход · **Обновлено:** 23.10.2026 · **Ответственный:** Анна Киракосян (FE, UX/UI)

## Общие принципы

- У каждого экрана с данными — минимум 4 состояния: **загрузка, успех, нет данных, ошибка**.
- Состояния понятны, предсказуемы и выглядят одинаково на всех экранах.
- Пользователь всегда знает, что происходит: идёт загрузка, есть результат, что можно нажать, что делать дальше.
- Введённый текст никогда не теряется из-за ошибки (черновик рецензии сохраняется).

| Состояние | Когда | Что видно |
|---|---|---|
| Загрузка | Данные запрашиваются | Индикатор загрузки на месте контента |
| Успех | Данные получены | Экран в задуманном виде |
| Нет данных | Данных пока нет | Текст-пояснение + действие («Перейти в каталог», «Оставьте первую рецензию») |
| Ошибка | Данные не получены | Понятное сообщение + действие («Повторить», «Вернуться») |

**Переходы:** нажатие → «Загрузка» или «Отправка»; успешный ответ → «Успех»; ошибка → «Ошибка» с возможностью повторить.

## Ошибки сервера

| Код | Что видит пользователь |
|---|---|
| Нет сети или таймаут > 10 с | «Нет связи с сервером. Проверьте интернет и повторите» + «Повторить» |
| 401 (сессия истекла) | Попытка обновить сессию; если не вышло — «Сессия истекла, войдите снова» → вход, черновик сохраняется |
| 403 | «Это действие вам недоступно» |
| 404 | «Страница не найдена» + ссылка на главную |
| 409 `USERNAME_TAKEN` | «Этот логин уже занят» у поля логина |
| 400 / валидация | Сообщение у конкретного поля |
| 500 | «Что-то пошло не так на нашей стороне. Попробуйте позже» |

## Состояния по экранам

### Вход и регистрация (зритель и автор)
| Состояние | Что видно |
|---|---|
| Начальное | Пустая форма |
| Ввод | Подсказки и ошибки валидации у полей |
| Отправка | Кнопка неактивна, индикатор |
| Успех | Переход в профиль, к черновику рецензии или туда, откуда пришёл; у автора — в Эхо Studio |
| Ошибка | Сообщение (неверные данные, логин занят, слабый пароль) |
| Заявка автора | «Заявка отправлена. Кабинет откроется после подтверждения роли» |

### Главная, каталог, поиск
| Состояние | Что видно |
|---|---|
| Загрузка | Индикатор |
| Успех | Блоки, сетка карточек, счётчик «Найдено» |
| Нет данных | «Фильмов по выбранным фильтрам нет», «Ничего не найдено среди …» |
| Ошибка | Сообщение + «Повторить» |
| Поиск: начальное | «Введите название фильма, режиссёра, автора или пользователя» |

### Страница фильма и страница автора
Загрузка · Успех · Ошибка (фильм или автор не найден → 404) · Нет данных в блоках: «Рецензий пока нет», «Состав пока не добавлен», «Подтверждённые работы пока не добавлены».

### Форма оценки и рецензии
| Состояние | Что видно |
|---|---|
| Гость | Форма доступна; при отправке — вход, черновик сохраняется |
| Ввод | Итог пересчитывается при движении ползунков; счётчик символов; «Черновик сохранён» |
| Ошибка валидации | «Для рецензии нужно минимум 150 символов» |
| Подтверждение | Окно с предпросмотром и отметкой о спойлерах; без текста — «Сохранить только оценку?» |
| Отправка | Индикатор, кнопка неактивна |
| Успех | «Рецензия отправлена на модерацию» / «Оценка сохранена» |
| Ошибка | Сообщение, текст рецензии не теряется |

### Профиль
Загрузка · Успех · Редактирование · Сохранение · Ошибка · Нет данных («Пока нет рецензий», «Пока ничего не выбрано» в предпочтениях).

### Кнопки-переключатели
| Элемент | Состояния |
|---|---|
| Лайк | Не поставлен (серый) · Поставлен (розовый) · Ошибка (откат + уведомление) · У автора — только просмотр числа |
| Лайк автора (Studio) | «☆ Поставить лайк автора» (пунктир) · «★ Лайк автора» (оранжевый) · Ошибка (откат + уведомление) |
| В предпочтениях | Не добавлено · Добавлено (розовая рамка) · Топ-5 заполнен (переход к редактированию) · Гость (переход ко входу) · Только просмотр (автор, Studio) |

### Мобильный телефон (< 768 px)
Экран-заглушка: логотип, что такое «Эхо», «Откройте на компьютере или планшете», ссылки на лендинг и соцсети.

### Уведомления
Всплывают справа снизу и пропадают через 2–5 секунд (действия автора — 5 с). Новое уведомление заменяет предыдущее.
