# Актуальные требования к продукту

> **Цель:** описать, что должен уметь продукт к запуску; использовать как критерий приёмки · **Обновлено:** 23.10.2026 · **Ответственный:** Роман Стяжкин (PM)

Статусы: ✅ есть в интерфейсе v10.30 · 🔌 нужна интеграция с бэкендом · ⏳ после релиза.

## 1. Назначение

Платформа для осмысленного взаимодействия с кино через оценки, рецензии и общение. Пользователь может:
- выразить своё восприятие произведения и объяснить его рецензией;
- узнать восприятие других;
- сформировать свою историю взаимодействия с кино;
- найти единомышленников;
- взаимодействовать с авторами фильмов и медиа.

Платформа подталкивает идти вглубь: **Просмотр → Впечатление → Оценка → Рецензия → Взаимодействие**.

## 2. Роли

| Роль | Кто | Что делает |
|---|---|---|
| **Зритель** | Любой зарегистрированный пользователь | Оценивает, пишет и читает рецензии, ставит лайки, ведёт профиль и предпочтения |
| **Медиа** | Издание или критик (роль выдаётся вручную) | Публикует экспертные рецензии и оценки. Медийная оценка учитывается отдельно |
| **Автор** | Создатель фильма, прошедший верификацию | Работает в Эхо Studio: лайки автора, авторские комментарии, просмотр мнений о своих работах |
| **Администратор** | Команда | Модерирует рецензии и регистрации, редактирует карточки |

Внутренние сегменты вовлечённости (Авторизованный, Новый, Постоянный, Остывший, Ушедший) пользователю не видны — см. [сегменты](engagement-segments.md).

## 3. Аккаунт

### 3.1. Без регистрации
Гость попадает сразу на главную и видит контент. Он может просматривать каталог, карточки фильмов, рецензии и профили. У кнопки профиля, в профиле и в форме оценки показывается предложение войти. ✅

### 3.2. Регистрация
- Поля: **логин (он же никнейм) и пароль**. Аватар, никнейм и био настраиваются в профиле после входа. ✅
- Без подтверждения почты: почтовая регистрация готова на бэкенде, но выключена до оформления согласия на обработку персональных данных.
- Пароль — от 8 символов (требование бэкенда). 🔌

### 3.3. Вход и сессия
Пользователь может войти, выйти и сохранить вход между посещениями. 🔌
Нужно корректно обрабатывать: неверный логин, неверный пароль, занятый логин при регистрации, истёкшую сессию, повторный вход. 🔌

### 3.4. Вход автора
Отдельная форма «Для авторов» → кабинет Эхо Studio. Регистрация автора — это заявка, кабинет открывается после подтверждения роли. ✅ 🔌

### 3.5. Незавершённая рецензия
Если гость начал писать рецензию, черновик сохраняется. После входа пользователь возвращается к нему. ✅

## 4. Навигация
Шапка: логотип · Главная · Каталог · строка поиска · профиль (или «Войти»; у автора — «Эхо Studio» и профиль). ✅
Основной путь: **Главная → фильм → мнения сообщества → своя оценка / рецензия**.

## 5. Главная

| Блок | Содержимое | Статус |
|---|---|---|
| Тезис | Что это за платформа и зачем она | ✅ |
| Сейчас обсуждают | Последние рецензии: аватар, никнейм, статус, фильм, оценка с параметрами, заголовок, свёрнутый текст, лайки, лайк автора, дата | ✅ |
| Популярное | Постеры с тремя итоговыми оценками, названием, годом, режиссёром | ✅ |
| Последние авторские комментарии | Фильм, автор, заголовок, текст, лайки, дата | ✅ |
| Блок партнёров | Партнёрские интеграции собраны в одном блоке | ⏳ |
| Последние добавленные фильмы, активность медиа | — | ⏳ |

## 6. Каталог
Карточки: постер, название, год, жанр, режиссёр, количество рецензий и оценок, три итоговые оценки. Фильтры: жанр, год, страна. Сортировка: лучшие, новые. Счётчик «Найдено». ✅
Состояния: загрузка, ошибка, нет результатов, результаты. 🔌

## 7. Поиск
Строка в шапке. Вкладки **Все / Фильмы / Люди / Авторы**; каждая ищет только по своей категории. Счётчик найденного и сообщение «Ничего не найдено среди …». ✅
Состояния: загрузка, ошибка. 🔌

## 8. Страница фильма

| Часть | Содержимое | Статус |
|---|---|---|
| Информация | Постер, название, год, жанр, страна, описание, режиссёр (ссылка на страницу автора) | ✅ |
| Оценки | Итоговая оценка + три средние: по рецензиям, без рецензий, медиа. Раскрываются пять параметров каждой; подсказка у каждого параметра | ✅ |
| В предпочтениях | Счётчик; нажатие добавляет в топ-5 (если топ-5 заполнен — переход к редактированию предпочтений) | ✅ |
| Съёмочная группа | Слайдер: вкладки «Актёры» и «Команда», переход на страницу автора | ✅ |
| Авторский комментарий | Если есть — оранжевый блок над рецензиями: заголовок, автор, специальность, текст, лайки, дата | ✅ |
| Форма | Пять ползунков с подсказками, итог в реальном времени, заголовок, текст (150–10 000 символов), правила, подтверждение публикации с отметкой о спойлерах. Без текста — сохраняется только оценка | ✅ 🔌 |
| Рецензии | Сортировка: новые, популярные, старые. Длинные свёрнуты; со спойлерами скрыты до подтверждения. Лайк и плашка «★ Лайк автора» | ✅ 🔌 |

## 9. Система оценок
Четыре параметра **качества** и **впечатление** как множитель → итог от 0 до 100. Параметры итоговой оценки должны быть доступны везде, где она показана. Подробно — в [системе оценок](ratings-and-statuses.md).

## 10. Рецензии
Оформление — по [требованиям к оформлению](review-design.md). Одна рецензия на фильм; без редактирования и удаления; публикуется после модерации. 🔌

## 11. Лайки
- Зритель ставит и снимает лайк на рецензии. ✅ 🔌
- **Лайк автора** ставит только автор, только на рецензии к своим фильмам, только в Эхо Studio. Показывается рядом с обычными лайками. ✅ 🔌
- Автор не ставит обычные лайки. ✅
- Лайк медиа как отдельный тип — ⏳

## 12. Профиль зрителя
- Аватар, никнейм, био, дата регистрации, статус-светлячок с баллами и прогрессом, окно «Лестница статусов». ✅
- Статистика: рецензии, оценки, полученные и поставленные лайки, полученные лайки автора. ✅
- Предпочтения: топ-5 фильмов, режиссёров, актёров. ✅
- Вкладки «Рецензии» и «Оценки», сортировка: новые, популярные, старые. ✅
- Свой профиль: редактирование аватара, никнейма, био, предпочтений (с поиском); выход. ✅ 🔌

## 13. Автор

### Публичная страница автора
Фото, имя, отметка о верификации, специальность, счётчик «в предпочтениях», статистика (авторские комментарии, оценки, лайки автора), средние оценки работ. Вкладки: Фильмография (сортировка новые, старые, популярные), Рецензии, Авторские лайки, Оценки. Кнопка возврата ведёт туда, откуда пришли. ✅

### Эхо Studio (кабинет автора)
| Раздел | Что есть |
|---|---|
| Обзор | Метрики (в предпочтениях, рецензии, лайки автора, средняя оценка), сводка по фильму, последние мнения |
| Фильмография | Работы автора с тремя оценками |
| Мнения зрителей | Рецензии только на работы автора; кнопка «Поставить лайк автора» |
| Авторские комментарии | Выбор фильма, заголовок, текст, живой предпросмотр, публикация с подтверждением. Новый комментарий заменяет прежний |
| Мой профиль | Как публичная страница + ссылка на неё. Предпочтений в Studio нет |

Переход на сайт и выход — в боковом меню. ✅ 🔌

## 14. Медиа
Роль показывается на рецензиях. Отдельный профиль медиа с собственной визуальной идентичностью — ⏳

## 15. Состояния интерфейса
Для всех динамических элементов: загрузка, пусто, ошибка, успех. См. [состояния](ui-states.md). 🔌

## 16. Система вовлечения
Статус по баллам за целевые действия (рецензии, оценки, лайки, лайки автора). Статус виден на рецензиях и в профиле и выделен цветом. ✅ См. [статусы](ratings-and-statuses.md).

## 17. Устройства
- Основная платформа: **десктоп, ноутбук, планшет** (от 768 px).
- На телефоне — экран-заглушка: что такое «Эхо», совет открыть на компьютере, ссылки на лендинг и соцсети.
- Лендинг для авторов — полностью адаптивный.

## 18. Внешние интеграции
- **TMDB** — данные о фильмах: списки, карточки, поиск, изображения, состав. Нужны обработка ошибок и работа при недоступности. 🔌
- **Яндекс.Метрика и Google Analytics 4** — аналитика. ⏳ спринт 7

## 19. API
Бэкенд даёт фронтенду стабильный контракт. Для каждого эндпоинта определены URL, метод, параметры, тело запроса, ответ, коды и структура ошибок, требования авторизации. См. [API и интеграция](../04-development/api-integration.md).

## 20. Продуктовая аналитика (AARRR)
- **Acquisition:** источник перехода (UTM), новые пользователи.
- **Activation:** первое осмысленное действие — первая оценка, первая рецензия, добавление в предпочтения.
- **Retention:** возвраты, повторные оценки и рецензии, регулярное чтение рецензий.
- **Главная метрика:** NSM = рецензии / WAU / неделя.

План событий — в [аналитике](../05-business/analytics-plan.md).
