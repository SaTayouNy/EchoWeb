# Программа социального развития до 01.01.2027

> **Цель:** сформировать первое ядро авторов и зрителей, запустить регулярную коммуникацию и проверить первые механики взаимодействия · **Обновлено:** 23.10.2026 · **Ответственный:** Роман Стяжкин (PM)

**Период:** 12 недель. **Фокус:** не массовый охват, а небольшое активное ядро — первые авторы, содержательные публикации, повторное участие.

**Приоритеты:** P0 — обязательно · P1 — после P0 или параллельно · P2 — только при достаточной активности.

## A. Привлечение авторов

| Приоритет · срок | Задача | Результат | Кто | Трудоёмкость |
|---|---|---|---|---|
| P0 · нед. 1 | **Портрет автора:** категории (рецензенты, критики, авторы каналов, киноклубы), ценность для них, критерии отбора | Профиль автора и аргументы приглашения | PM | 0,5–1 ч.-дн. |
| P0 · нед. 1–2 | **Пакет приглашения:** презентация, персональное сообщение, FAQ | Материалы для онлайн- и офлайн-коммуникации | PM, дизайнер | 1–2 ч.-дн. |
| P0 · нед. 1–2 | **Лендинг для авторов** — см. [ТЗ](landing-brief.md) | Лендинг с рабочей формой отклика | PM + FE | 2–4 ч.-дн. |
| P0 · нед. 2–4 | **Поиск и приглашения:** база, персональные обращения, повторные касания | База со статусами «найден → приглашён → ответил → договорились → подключён» | PM | 3–5 ч.-дн. |
| P0 · нед. 3–12 | **Коммуникация:** сообщения, встречи, мероприятия, сопровождение подключения | Первые авторы с публикациями | PM | 1–2 ч.-дн. / нед. |
| P1 · нед. 5–8 | **Онбординг:** инструкция, помощь с профилем и первой публикацией | Путь от согласия до первой публикации | PM, FE | 1–2 ч.-дн. |
| P1 · нед. 9–12 | **Удержание:** обратная связь, темы и релизы, регулярный формат | План работы с активными авторами | PM | 1 ч.-дн. |

Численную цель по авторам ставим через 2–3 недели по фактической конверсии.

## B. Сообщество внутри платформы

| Приоритет · срок | Задача | Результат | Кто | Трудоёмкость |
|---|---|---|---|---|
| P0 · нед. 1–2 | **Базовый сценарий:** путь от фильма к рецензии и реакции; что уже есть в MVP | Сценарий и список пробелов без расширения MVP | PM | 1 ч.-дн. |
| P0 · нед. 2–4 | **Стартовое наполнение:** фильмы, содержательные рецензии, согласие авторов на размещение | Новым пользователям есть что читать | PM + авторы | 2–4 ч.-дн. |
| P1 · нед. 5–8 | **Подсветка сообщества:** подборка активных авторов или рецензий по прозрачным критериям | Способ находить авторов и материалы | PM + FE/BE | 1–2 ч.-дн. + разработка |
| P1 · нед. 6–9 | **Формат «автор — медиа — зритель»:** пилотный материал или обсуждение | Один проверенный формат | PM + авторы | 2–3 ч.-дн. |
| P2 · нед. 9–12 | **Пилот общественной премии** | Концепция и, при наличии ядра, небольшой пилот | PM | 3–5 ч.-дн. |
| P2 · нед. 10–12 | **Интерактив:** подборка с обсуждением или вопрос недели | Решение о повторении | PM + сообщество | 1–2 ч.-дн. |

Топ пользователей и премия не обязательны в первый месяц: при малом числе участников рейтинги нерепрезентативны. Новые функции — только через [запрос на изменение](../02-management/change-management.md).

Роли площадок — в [функциях соцсетей](social-functions.md), тон — в [редакционном гайде](editorial-guide.md).

## Контроль

| Направление | Что отслеживаем ежемесячно |
|---|---|
| Авторы | Найдено, приглашено, ответили, согласились, подключены, первые публикации |
| Сообщество | Активные авторы и пользователи, рецензии, участие в пилотах |
| Соцсети | Подписчики, охват, реакции, переходы на сайт, регистрации из каналов (UTM) |
| Качество | Содержательные комментарии, повторные публикации, возвраты |

Число подписчиков — не единственный показатель: важнее переходы, участие и публикации.

## Ресурсы
- **PM:** владелец программы, ориентировочно 4–7 ч.-дн. в неделю в активные периоды. При нехватке ресурсов первыми сокращаются премия и интерактивы.
- **Дизайнер:** лендинг, оформление площадок, шаблоны.
- **FE / BE:** доработки лендинга и выбранных механик — с отдельной оценкой.
- **Авторы и медиа:** участие по договорённости.

**Критерий успеха:** небольшая группа людей, которые публикуют рецензии, читают и обсуждают чужие мнения, возвращаются и готовы участвовать в развитии платформы.
