# Эхо — основной сайт (v10.30)

Актуальный интерфейс платформы «Эхо»: сайт для зрителей и кабинет авторов «Эхо Studio».
Собирается Vite на чистом JavaScript без фреймворка. Внешний вид и сценарии совпадают с согласованным прототипом `index.html` v10.30.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev        # локально, по умолчанию http://localhost:5173
npm run build      # сборка в папку dist/
npm run preview    # просмотр собранной версии
```

Без настроек сайт работает на демо-данных. Вход как зритель и как автор имитируется, логин и пароль можно не вводить.

## Подключение бэкенда

1. Скопируйте `.env.example` в `.env`.
2. Укажите адрес API:
   - на сервере, если nginx проксирует `/api` на бэкенд: `VITE_API_URL=/api`;
   - локально с бэкендом на `http://localhost:8000`: `VITE_API_URL=/api` и `VITE_DEV_PROXY=http://localhost:8000`.
3. Пересоберите проект: `npm run build`. Адрес API вшивается в сборку.

Инструкция для бэкенда — **[BACKEND.md](BACKEND.md)**, полный контракт (пути, тела запросов, форматы ответов) — **[API.md](API.md)**.
Все запросы к серверу собраны в **`src/api.js`**, другие файлы трогать не нужно.

## Структура

```
index.html              каркас страницы
public/favicon.png      иконка сайта
src/app.js              интерфейс: страницы, состояния, сценарии
src/styles.css          все стили
src/api.js              обмен данными с сервером (или демо-данные, если VITE_API_URL пуст)
src/mock-data.js        демо-данные; их формат = формат ответов API
src/placeholders.js     картинки-заглушки
src/assets/echo-mark.png  логотип
API.md                  контракт API для бэкенда
BACKEND.md              порядок подключения бэкенда и бизнес-правила
```

## Выкладка на сервер

После `npm run build` содержимое папки `dist/` — обычные статические файлы. Node.js на сервере не нужен.
Пример nginx для поддомена сайта:

```nginx
server {
  server_name app.example.ru;
  root /var/www/echo/dist;
  location / { try_files $uri /index.html; }
  location /api/ { proxy_pass http://127.0.0.1:8000/; }   # бэкенд
}
```

## Отладка

Если открыть сайт с параметром `?debug` (например, `http://localhost:5173/?debug`), в консоли браузера будет доступно состояние интерфейса: `window.__echo.state`.
